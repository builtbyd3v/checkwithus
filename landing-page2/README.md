# landing-page2

The **checkwith.us** landing page: plain HTML, CSS and JavaScript, no framework, no build step.

It was first built as a study of another site's layout and motion system. Everything
visible is now checkwith.us's own: copy, logo, phone screens, icons and QR code are
original (generated by `tools/make_assets.py`), so there is nothing third-party to clear
under `docs/RULES.md`. Inter, Inter Tight, Instrument Serif and Quicksand are open
fonts (OFL) and GSAP 3.13 is free for this use.

This folder is still listed in this clone's `.git/info/exclude`, so nothing here is
committed. To ship it, copy it into a branch and open a PR like any other change.

## Run it

```bash
cd landing-page2
python -m http.server 4173      # or any static server
# open http://127.0.0.1:4173/
```

Everything it needs is local, so it works offline. Serve it rather than opening the file
directly, because browsers can block fonts over `file://`.

## Files

```
index.html            the page
css/styles.css        one stylesheet, organised by section
js/main.js            navigation, scroll motion, pointer effects
tools/make_assets.py  regenerates every logo, phone screen, icon and the QR code
assets/img/           logo, four phone screens (SVG), wordmark, QR code
assets/icons/         feature, step and tick icons
assets/fonts/         Inter Tight, Inter, Instrument Serif (italic), Quicksand
assets/vendor/        GSAP 3.13.0 + ScrollTrigger
```

Edit the phone screens or icons in `tools/make_assets.py` and run
`pip install fonttools brotli qrcode` then `python tools/make_assets.py`. Text in the
SVGs is converted to outlines, so they look identical on every device.

## Behaviour

- Fixed pill header, transparent at the top and solid after the first scroll; hamburger on
  narrow screens (closes on Escape, outside click, link click, or growing past 1240 px).
- Hero entrance, per-section scroll reveals, card glow and footer wordmark spotlight that
  follow the pointer, smooth anchor scrolling with a header offset.
- `prefers-reduced-motion`: everything visible, nothing animates. If scripts fail, a 2 s
  timer releases the hero so the page is never blank.
- Responsive breakpoints at 1240, 1024, 880, 767, 700 and 460 px.

## Things to know

- **Links to the app** point at `https://checkwith.us/auth/login?returnTo=/dashboard` and
  assume that is where the Next.js app is deployed. Change them in `index.html` if the
  domain or route differs.
- **Colours** are the colorway yellow `#FFCC33` and crimson `#B22435`, set as tokens at the top of `css/styles.css` and in `tools/make_assets.py` (for the SVG graphics). The Next.js app itself still uses teal.
- **No analytics or tracking.**
- A few unused class names and a hidden `#testimonials` rule remain in the CSS from the
  original structure. They have no effect.
